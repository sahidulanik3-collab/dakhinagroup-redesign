# Security Policy: Dakhina Group

## Supported Versions
Security updates are actively applied to the main branch of this repository.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
Dakhina Group treats cybersecurity and confidential client protections with the highest degree of seriousness. 

If you discover a security vulnerability or sensitive information exposure:
1. **DO NOT** open a public GitHub issue.
2. Email your report to: `security@dakhinagroup.com` or `info@dakhinagroup.com`.
3. Include detailed steps to reproduce, affected endpoints, and potential impact.
4. Our technical security team will acknowledge receipt within 48 hours and work with you on prompt remediation.
